## 准入规则与构建开关

按配置判断：baseline/candidate 配对中位数 **>1.02**、数值审查通过、
SMT 兄弟核心至少 99.9% 空闲且 steal 为零，C4 与真实 5950X 均须满足。
回退控制项单独报告，不使用旧的“全部控制项 1%”规则。
每组目标 45 秒，配置上限 60 秒；校准、进程初始化和预热计入组预算，
报告的每帧时间仅计实际滤镜请求。未完成配对被丢弃，完整历史组不重跑挑选结果。
重型配置只有 1–3 对时如实记录；单配对的退化 bootstrap 区间不能视为可靠统计置信度。

- 默认：`NSS_AVX2_DEFAULTS=ON`，`NSS_AVX2_EXPERIMENT=0`。
- 参考路线：两个开关分别设为 `OFF`、`0`。
- 单独试验：关闭 defaults，再指定 experiment 位。
- `NSS_BM_EXPERIMENT=2305` 不变；公开 VapourSynth 参数不变。
- 新 SIMD 实现均限定 `HWY_TARGET == HWY_AVX2`。

默认编译候选掩码为 1789，但实际启用由不可变的任务参数决定，
不是把掩码无条件应用到所有算法。权限沿宿主、批处理和底层调用传递，没有新增线程局部或全局可变派发状态。

## 数值与语义

容许累加舍入误差，仍先检查 `max_abs≤1e-5`、`RMSE≤1e-6`。
超限保留数组，只有因果重放与 clean PSNR 损失 ≤0.05 dB、SSIM 损失 ≤0.001 都通过才准入。
派生审查文件以原始数组内容哈希匹配重放；原始失败标记和配对记录不被改写。

- NLH：每次公开调用内部已经包含 Basic、Wiener 两遍。
  原始记录的 `basic` 表示无 rclip，`wiener` 表示 rclip=clip，`two_stage` 表示串接两次 NLH 调用。
  它们不是单独暴露的内部阶段。底层另有标量 gather/Haar/滤波对照。
- NLH 外部串接的局部差异约 0.00105；固定参考时差异只有约 5.96e-7，
  仅改变参考图，旧实现也重现局部放大。clean PSNR 损失约 0.000252 dB，SSIM 改善。
- b16 DCT：匹配和输入组相同，独立 double 3D DCT 定位到硬阈值边界舍入。
  最大误差像素可由组输出和权重精确重构；g1 Basic 的 clean PSNR 损失约 0.0000047 dB。
  串接用固定参考交叉重放，并单独审查第一遍阈值变化。
- 早期 DCT 重放漏乘公开 BM3D sigma 的 0.75 因子，已用 `INVALID.txt` 明确废止。
  有效 v3 重放同时校验该换算和最大误差像素重构；不使用早期的误判通过。
- 初始新 matcher oracle 错把未改变的 b8/g8 视为通用归约树，已修正测试范围。
  b4 的一次实现修订固定 GCC 重排前的 `(0+3)+(1+2)` 归约顺序。

## 构建与验证边界

C4：Xeon Platinum 8581C、GCC 13.3、Highway 1.4、VapourSynth R75。
5950X：16 核/32 线程，实际探测物理核心和 SMT 兄弟；使用已有 R78/NumPy 2.5.1，未安装系统组件，未停止用户进程。
主 A/B 在两机使用相同的 C4/GCC13 强制 AVX2 插件；另验证普通 dynamic 构建。
5950X 原有 GCC15.2 编译的**未修改基线**先在 SVD 测试失败；同一 C4/GCC13 基线在该 CPU 通过。
该原生 GCC15 构建兼容性问题保留，不归因于本轮修改，也不声称已修复。

- 普通 AVX2：18/18 CTest；lab：20/20 CTest。
- 最终强制 AVX2：230 项矩阵通过，C4 最大绝对差约 4.77e-7；另有 28 项配置补充对照。
- AVX3：230 项矩阵逐值相同。原型全掩码与基线插件曾字节相同。
  配置派发接入后整库机器码不同；108 个共有 AVX3 函数中 107 个向量指令统计相同，
  剩余 Bm3dFilterGroup 仅搬运指令统计改变，向量算术计数相同。
  8 组整滤镜回归 0.9921–1.0097×，数值及环境均通过。
- dynamic 构建的有效 C4 对照使用 AVX3 基线；早期跨 ISA 对照不用于准入。
- 性能输入是静态图及其重复帧；不将 temporal 数字外推成自然运动视频吞吐结论。
